# ECS Structural Authority R0

Elpis now carries a prospectively defined ECS structural candidate contract,
`MICROSCOPIC_COLUMN_PARTICIPATION_MASK_R0`, for a frozen cubic ECS reference
family. The contract treats microscopic column slots as operational gauge
addresses rather than intrinsic semantic entities. Each exact nonzero frozen
whole column has one binary ACTIVE/DISABLED participation state. Structural
operations are limited to ABSTAIN, DISABLE_COLUMN, and RESTORE_COLUMN;
continuous column bytes remain frozen and restoration reproduces the exact
retained bytes. The contract is independent of Grid81 and does not establish
Semantic-IR representability, Grid81 compatibility, learned refinement
efficacy, scientific improvement, or evolutionary benefit.

## Normative contract

The normative public contract consists of:

- `SELECTED_ONTOLOGY_SPEC.json`
- `EDIT_IDENTITY_CONTRACT.json`
- `MATERIALIZATION_CONTRACT.json`
- `MUTATION_GRAMMAR.json`
- `FROZEN_WRITABLE_BOUNDARY.json`
- `EQUIVALENCE_AND_GAUGE_ANALYSIS.json`

These normative files are carried forward byte-for-byte from the closed local
R0 authority. `SHA256SUMS` binds this bounded public set.

The reference-family digest and source-scope fields in the normative files are
opaque contract bindings. The private/local scientific source and evidence used
to qualify those bindings are intentionally not published here.

`FROZEN_WRITABLE_BOUNDARY.json` retains the closed R0 statement that imported
reference bytes are frozen. In this public representation, those private/local
reference bytes remain external provenance and are not a public repository
dependency.

## Structural state and mutation boundary

For each exact nonzero frozen whole column, the writable structural state is
binary ACTIVE/DISABLED. Exact-zero frozen columns are FROZEN_ZERO and
non-writable.

`DISABLE_COLUMN` materializes six exact binary64 `+0.0` values in the existing
column slot without changing `N`. `RESTORE_COLUMN` restores the exact retained
frozen column bytes. No random initialization, interpolation, learned recovery,
continuous parameter update, width change, or primitive-law change is part of
the R0 mutation grammar.

Column slot indices are operational addresses only. They do not create
intrinsic entities. Simultaneously permuting the frozen columns and their
participation states represents the same structural state under the closed R0
equivalence relation.

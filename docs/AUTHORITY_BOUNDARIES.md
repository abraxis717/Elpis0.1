# Authority Boundaries

## What Elpis decides

- Structural D4 group actions on 81-cell grids
- Canonical serialization and orbit compilation
- Deterministic retrieval within bounded budgets
- Receipt-bound transaction lifecycle
- Capability authority evaluation and scope
- Canonical promotion gate decisions
- Darwinian episode selection and heredity

## What Elpis does NOT decide

- Model weight updates or parameter training
- Online serving routing or load balancing
- Governance policy or Constitution enforcement
- Persistent memory writes or state persistence
- Expert loading or inference scheduling
- Runtime admission or production deployment approval

## Runtime admission

Runtime admission is **FALSE**. The qualified system produces structurally deterministic, receipt-bound execution traces but does not authorize online serving.

## Jurisdiction

Elpis operates within the domain of deterministic structural transformation. Inputs outside the defined contract surface (e.g., malformed grids, unknown opcodes, out-of-bound indices) are rejected with explicit error states, not silently defaulted.

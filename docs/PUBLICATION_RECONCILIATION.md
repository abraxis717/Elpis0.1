# Publication Reconciliation Policy

The public GitHub repository is preservation authority for material already published.

Local Elpis copies may contain newer development state, but local absence must not be interpreted as evidence that a published file should be removed.

## Rules

1. Existing public content is preserved by default.
2. Reconciliation is additive-first.
3. No published file is replaced from a local copy solely because the local copy appears newer.
4. No published file is deleted because it is absent from a local copy.
5. Existing-file modification requires independent comparison and an explicit reason.
6. Experimental or retired learned-model lineages must remain distinguishable from qualified deterministic components.
7. Runtime admission remains a separate decision from preservation or publication.

This policy exists because some local copies were produced through scrubbed or incomplete transfer paths and cannot safely serve as deletion authority.

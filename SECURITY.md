# Security Policy

## Scope

Elpis is a structural core system. This security policy covers the deterministic structural components, native retrieval library, and runtime transaction layers.

## Reporting vulnerabilities

Report security vulnerabilities to the project maintainers. Do not open public issues for security-sensitive findings.

## What is in scope

- Native HACF library memory safety
- Runtime transaction receipt integrity
- Canonical promotion gate logic
- D4 group action correctness

## What is out of scope

- Model weights or inference engines (not included)
- Online serving endpoints (not included)
- External service dependencies (none)

## Supported versions

Only the latest release is supported.

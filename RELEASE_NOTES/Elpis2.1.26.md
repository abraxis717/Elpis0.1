# Elpis2.1.26

## Version: v2.1.26

Elpis2.1.26 is the repository-identity and distribution-metadata successor to Elpis2.1.25 following the canonical GitHub repository rename to `abraxis717/Elpis`.

## Repository identity

The live public repository is now:

- `https://github.com/abraxis717/Elpis`
- Git clone URL: `https://github.com/abraxis717/Elpis.git`

Current package metadata, citation metadata, publication authority, public-overlay identity, README release metadata, and their regression contracts are updated to the new canonical repository identity.

Historical qualification records, prior release notes, prior release manifests, and other immutable evidence are not rewritten merely because the repository was renamed.

## Distribution identity

The Python distribution project remains **`elpisai`**. The console command remains **`elpis`**, and the established Python import-package names remain unchanged. The unrelated PyPI project named `elpis` is not this repository.

## Preserved implementation and authority

This release changes repository/distribution metadata and release provenance only. It does not broaden or alter:

- runtime admission or terminal execution authority;
- structural-guidance semantics;
- Grid81 Publisher R1 mechanics;
- StreamingRegexIngress/RegexHACF V2 mechanics;
- ECS M1A code or frozen ECS Structural R0 authority;
- closed Branch35–40 scientific evidence.

`PUBLISHED_RELEASES.json` is intentionally unchanged in the pre-tag candidate. Publication-registry materialization remains a separate post-tag step after hosted CI and immutable tag admission.

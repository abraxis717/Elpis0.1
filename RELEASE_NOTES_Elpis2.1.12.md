# Elpis2.1.12

## Version: v2.1.12

Elpis2.1.12 is the qualified successor to Elpis2.1.11. It publishes and seals
the already-qualified ECS Structural Authority R0 contract while preserving the
existing production runtime authority contracts.

## Qualified ECS Structural Authority R0

- The selected prospective ontology is
  `MICROSCOPIC_COLUMN_PARTICIPATION_MASK_R0`.
- Microscopic column slots are operational gauge addresses, not intrinsic
  semantic entity identities.
- Simultaneous column permutation remains an equivalence.
- Each exact nonzero frozen whole column has one binary ACTIVE/DISABLED
  participation state.
- Exact-zero frozen columns remain non-writable `FROZEN_ZERO`.
- `DISABLE_COLUMN` materializes six exact binary64 `+0.0` values in the existing
  slot without changing width `N`.
- `RESTORE_COLUMN` reproduces the exact retained frozen column bytes.
- The structural mutation grammar is limited to `ABSTAIN`, `DISABLE_COLUMN`,
  and `RESTORE_COLUMN`.
- Continuous column bytes, width, primitive law, and scientific observation
  authority remain frozen.
- S3 is not edit identity. No pairwise graph or module structure is introduced.

table, immutable predecessor belt, predecessor regression coverage, and
write-once release manifest required to incorporate the public ECS Structural
